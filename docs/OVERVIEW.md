## 🎯 项目定位

**Astraship 是什么？**

Astraship 是一个面向 AI Agent 的操作系统级平台，为智能体提供完整的运行环境、工具生态和协作机制。

**一句话定位**
> Astraship 是为 AI Agent 而生的操作系统，让开发者能够像构建传统应用一样轻松地构建、部署和管理智能体应用。

## 🏗️ 产品架构

### 五层架构模型

```
┌─────────────────────────────────────────────┐
│     Applications & Agents Layer             │  用户应用层
│     (各类 Agent 应用)                        │
├─────────────────────────────────────────────┤
│     Orchestration Layer                     │  编排层
│     (多 Agent 协作、工作流)                  │
├─────────────────────────────────────────────┤
│     Agent Runtime Layer                     │  运行时层
│     (生命周期、内存、工具执行)               │
├─────────────────────────────────────────────┤
│     Tool & Capability Layer                 │  工具层
│     (MCP 工具、内置工具、工具市场)           │
├─────────────────────────────────────────────┤
│     Infrastructure Layer                    │  基础设施层
│     (存储、网络、安全、监控)                 │
└─────────────────────────────────────────────┘
```

## 🔧 技术栈

### 后端
- **主语言**: TypeScript (Node.js 18+)
- **性能关键**: Rust
- **AI/ML**: Python 3.10+
- **Web 框架**: Express.js

### 前端
- **框架**: React 18+
- **状态管理**: Zustand
- **UI 组件**: shadcn/ui
- **构建工具**: Vite

### 数据存储
- **关系数据库**: PostgreSQL 15+
- **向量数据库**: Qdrant
- **缓存**: Redis 7+
- **消息队列**: RabbitMQ

### 基础设施
- **容器化**: Docker
- **编排**: Kubernetes (可选)
- **监控**: Prometheus + Grafana
- **日志**: Loki
- **追踪**: Jaeger
