# Astraship 生态组成

## 生态愿景

Astraship 不仅是一个技术平台，更是一个开放的 Agent 生态系统。我们致力于构建一个多方共赢的生态，连接开发者、工具提供商、企业用户和最终用户。

**需求特点**
- 快速部署

- 简单易用

**解决方案**
- **SaaS 版本**: 云端托管，按月付费

- **自助服务**: 在线文档和视频教程

**典型场景**
- 智能客服
- 销售自动化

- 内容生成工具

**需求特点**
- 高安全性要求
- 定制化需求

**解决方案**
- **私有化部署**: 本地部署或专有云

**典型场景**
- 企业知识管理
